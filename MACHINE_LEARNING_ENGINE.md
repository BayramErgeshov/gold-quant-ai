# PURPOSE

The Machine Learning Engine is responsible for discovering statistical relationships within market data.

Its purpose is not to predict the future with certainty.

Its purpose is to improve probability estimation using data-driven models.

Machine Learning never overrides the Research Departments.

It provides additional evidence.

---

# CORE PRINCIPLES

No black-box decisions.

Every prediction must be explainable.

Every model must be versioned.

Every model must be reproducible.

Every model must be tested.

Every model must be monitored.

Every model must be replaceable.
