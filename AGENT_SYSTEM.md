# AGENT PHILOSOPHY

Every agent has one responsibility.

No agent makes final trading decisions.

No agent can bypass the Chief AI.

Every agent produces an independent report.

Every report contains:

- Findings
- Confidence
- Supporting Evidence
- Opposing Evidence
- Historical Statistics
- Recommendation
- Unknowns

Agents never hide uncertainty.

# CHIEF AI DECISION RULE

No trade recommendation may be issued until every required department has completed its analysis or explicitly reported insufficient data.

Chief AI must always include:

Evidence supporting the recommendation.

Evidence against the recommendation.

Alternative scenario.

Confidence estimate.

Conditions that invalidate the analysis.

Reasoning must always be reproducible.
